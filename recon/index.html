The problem

Recon is a treadmill.

Every serious bounty hunter knows: the dupes are killers. Whoever spots the new staging subdomain, the new admin endpoint, the leaked S3 bucket first wins the bounty. The other 100 hunters get "Duplicate. Closed."

So you wake up, you cron your subfinder + httpx + nuclei pipeline, you babysit the diff, you grep through thousands of lines for what changed since yesterday. That's an hour gone before you've even started hunting.

BountyRecon does that hour for you. Every day. Across all your targets. Telegram ping when — and only when — something new appears.

How it works

Three things, fully automatic.

1. Add your program

After payment, you get a Telegram link. /addprogram tesla.com registers a target. Solo = 1 program, Pro = 5, Unlimited = no cap.

2. We diff every 24h

Subdomain enumeration (passive + active), endpoint discovery, tech fingerprint, JS file hashes. Stored. Compared against yesterday.

3. Telegram ping on NEW

Only deltas. Subdomain that didn't exist yesterday. Endpoint that changed status. Tech stack that flipped. Zero noise.

FAQ

Questions hunters ask.

Is this legal? Am I authorized to scan these targets?

BountyRecon performs only reconnaissance permitted under each program's public scope (passive DNS, public subdomain enumeration, HTTP fingerprinting on in-scope assets). You are responsible for adding only programs whose scope you are authorized to test under bug bounty rules. We mirror what you'd run yourself with subfinder/httpx — just every day, automatically, for you.

How fast do I get the first alert?

First baseline runs within 2 hours of activation. First diff alert lands within 24 hours of baseline. Subsequent diffs daily.

What channels — only Telegram?

v1 = Telegram only (instant, frictionless, hunters live there). Discord + email coming soon.

Can I cancel?

Yes — Stripe customer portal link in any alert message. One click cancel, no email needed.

What's the diff against false positives?

We track baselines for 7 days before flagging "new" — wildcard-DNS noise, ephemeral CDN edges, and CI staging subdomains get filtered out. You see real new attack surface.

Do I have to install anything?

Nothing. Pay → click Telegram link → /addprogram example.com. Done.
